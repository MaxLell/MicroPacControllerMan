# Firmware — MicroPacControllerMan

STM32G431RB Nucleo-64 firmware. Built with **CMake + arm-none-eabi-gcc**, low-level
init generated by **STM32CubeMX** (headless), flashed with **OpenOCD** over ST-LINK V3.

## Milestone 1 — Toolchain Bring-Up

Goal: prove the whole toolchain end-to-end — build, flash, and see the board run —
by blinking the on-board LED **LD2 (PA5)** and printing a heartbeat banner on the
**ST-LINK virtual COM port** (USART2, PA2/PA3, 115200 8N1). This is the target of
[VT-INT-005](../Docu/PrePlanning/06-Verification-and-Validation.md).

## One-time setup

1. **Build toolchain + flasher** (apt):
   ```
   sudo apt-get update && sudo apt-get install -y gcc-arm-none-eabi binutils-arm-none-eabi cmake openocd
   ```
2. **STM32CubeMX** (for init-code generation): download from ST
   (<https://www.st.com/en/development-tools/stm32cubemx.html>) and install. The
   installer bundles its own JRE. After install, either put `STM32CubeMX` on your
   `PATH` or export its location:
   ```
   export STM32CUBEMX=/path/to/STM32CubeMX/STM32CubeMX
   ```
3. **STM32Cube FW_G4 pack** (HAL/CMSIS): CubeMX downloads it automatically on the
   first code generation, or via *Help → Manage embedded software packages* →
   STM32G4.

## Build & flash

```
# 1) Generate the CubeMX init code (headless) from pacman.ioc
./tools/cubemx-generate.sh

# 2) Configure + build (CubeMX emits the CMakeLists + toolchain file)
cmake -B build -G "Unix Makefiles" -DCMAKE_TOOLCHAIN_FILE=cmake/gcc-arm-none-eabi.cmake
cmake --build build -j

# 3) Flash over ST-LINK V3
openocd -f openocd.cfg -c "program build/pacman.elf verify reset exit"

# 4) Watch the serial console (ST-LINK VCP)
stty -F /dev/ttyACM0 115200 raw -echo && cat /dev/ttyACM0
```

Expected: **LD2 blinks at ~1 Hz** and the console prints a periodic heartbeat line.

## Layout

- `pacman.ioc` — CubeMX configuration (G431RB, LD2/PA5 output, USART2 VCP, HSI clock).
- `tools/cubemx-generate.sh` — runs CubeMX headless to (re)generate init code.
- `openocd.cfg` — ST-LINK V3 + STM32G4 target config for flashing/debug.
- Application logic lives in the CubeMX `USER CODE` sections (survives regeneration);
  generated HAL/CMSIS/CMake files appear here after the first generation.

> The `.ioc` is authored to spec but is validated on the first headless generation —
> a minor key may need adjusting for your exact CubeMX version.
